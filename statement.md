# Problem Statement
Keeping track of simple account balances and transactions manually can cause mistakes. This project provides a menu-driven banking system that allows a user to manage basic account information through a Python console program.

## Scope of the Project
The project supports account creation, deposits, withdrawals, balance checking, account reports, transaction reports, and account deletion. It is an academic demonstration and is not a real banking application.

## Target Users
1) Students learning Python programming
2) Beginners who want to understand basic banking operations

## High-Level Features
1) Account management
2) Money deposit and withdrawal
3) Transaction recording
4) Account reporting
5) Input validation and error messages
