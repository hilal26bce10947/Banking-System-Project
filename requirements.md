# Requirements

## Functional Requirements
1. The user can create a bank account using an account number, name, and opening balance.

2. The user can deposit and withdraw money from an existing account.

3. The user can check the balance, view account details, view transaction details, and display all accounts.

4. The user can delete an existing account after confirmation.

## Non-Functional Requirements
1. **Usability:** The menu and prompts use simple language for beginners.

2. **Reliability:** The program checks whether an account exists before operating on it.

3. **Error handling:** Invalid money values and empty text input are handled without crashing the program.

4. **Maintainability:** Each feature is kept in a small function and related functions are placed in separate files.

5. **Performance:** Dictionary lookup provides quick access to accounts for this small console application.
